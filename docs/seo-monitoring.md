# دليل المراقبة وصيانة محركات البحث (SEO Monitoring Playbook) – منصة لِسيارتك

يهدف هذا الدليل التشغيلي إلى توفير خطة عمل دورية لفريق العمل لمتابعة أداء الموقع على Google Search Console (GSC)، وإدارة تحديثات الأسعار الشهرية، والتحقق المستمر من حداثة البيانات القانونية والضريبية.

---

## 1. الروتين الأسبوعي لمراقبة Google Search Console (GSC)

يتم تنفيذ هذا الروتين كل يوم إثنين في بداية الأسبوع:

### أ. فحص تقرير التغطية والفهرسة (Page Indexing Report)
1. **صفحات 404 أو خطأ خادم (5xx)**:
   - تأكد من عدم وجود أي خطأ زحف لصفحات المتاجر القديمة (Shopify)؛ حيث تم تحويل الروابط السابقة بـ 301 إلى أقرب حاسبة أو إرجاع 410 صريح.
2. **صفحات تم استبعادها بعلامة "noindex"**:
   - قارن القائمة بمصفوفة الحجب `seo-audit/gating-matrix.csv`.
   - يجب أن تتطابق الصفحات المحجوبة بدقة مع صفحات الدول غير المكتملة البيانات (الـ 562 صفحة noindex).
   - لا يجوز أبداً أن تظهر أي صفحة من الـ 32 صفحة المعتمدة أو الـ 27 حاسبة العامة في تقرير "تم استبعادها بعلامة noindex".
3. **صفحات بديلة مع علامة canonical مناسبة (Alternate page with proper canonical tag)**:
   - تحقق من أن جميع صفحات الدول غير المعتمدة تشير بنجاح إلى النسخة العامة كمرجع أصلي.

### ب. مراقبة استعلامات البحث وفرص تحسين النقر (Query & CTR Optimization)
1. الدخول إلى تقرير **الأداء (Performance)** وتصفية البيانات لآخر 7 أيام.
2. فرز الاستعلامات حسب **مرات الظهور (Impressions)** العالية مع **نسبة النقر (CTR)** المنخفضة (أقل من 3%).
3. فحص عناوين الصفحات (Titles) والأوصاف التعريفية (Meta Descriptions) ومطابقتها لنية الباحث:
   - إذا كان الباحث يبحث عن أرقام محددة (مثل "سعر بنزين 91 اليوم")، تأكد من إبراز الرقم في صندوق الإجابة المباشرة ووصف الميتا.
   - إذا كان البحث بلهجة محلية (مثل "كم تأمين الاستمارة" أو "حساب مكافأة نهاية الخدمة سمه")، أضف هذا المصطلح إلى `src/seo/keywords/index.ts` وأقسام الأسئلة الشائعة ذات الصلة.

## 2. بروتوكول التحديث الشهري لأسعار الوقود (Monthly Fuel Price Updates)

تعلن لجان تسعير الوقود في الدول العربية عن المراجعات الدورية لأسعار المحروقات (في اليوم الأخير من الشهر أو اليوم الأول من كل شهر ميلادي):

### أ. جدول المراجعة الدورية
- **الإمارات العربية المتحدة**: تعلن لجنة متابعة أسعار الوقود عن تسعيرة الشهر الجديد بين يومي 28 إلى 31 من كل شهر (تطبق في 1 من الشهر الجديد).
- **قطر**: تعلن قطر للطاقة عن الأسعار الشهرية في اليوم الأخير من كل شهر.
- **مصر**: مراجعة ربع سنوية من لجنة التسعير التلقائي للمنتجات البترولية.
- **السعودية**: سقف سعري مدعوم ومستقر بأمر ملكي كريم (بنزين 91: 2.18 ر.س، بنزين 95: 2.33 ر.س، ديزل: 1.15 ر.س).

### ب. خطوات التحديث البرمجي
1. فتح ملف بيانات الدولة المعنية: `src/data/countries/{cc}/index.ts`.
2. تحديث كائن `fuel.value.grades` بالأسعار الجديدة لكل لتر بالعملة الرسمية.
3. تحديث حقل `checkedAt` بتاريخ اليوم (مثلاً: `2026-12-01`).
4. إضافة سجل جديد في مصفوفة `priceHistory` للتوثيق التاريخي.
5. تشغيل فاحص الصلاحية:
   ```bash
   npm run check-stale
   ```
6. تشغيل الاختبارات وبناء الموقع:
   ```bash
   npm test
   npm run build
   ```
7. عمل commit رسمي وتصدير التحديث للنشر على Vercel.

## 3. معالجة البيانات المنتهية الصلاحية (Stale-Value Triage Workflow)

تم ضبط نظام حماية آلي يمنع تقديم بيانات قديمة للمستخدم عبر معيار `staleAfterDays`:
- أسعار الوقود: تنتهي بعد **35 يوماً**.
- ضرائب القيمة المضافة والأنظمة العمالية: تنتهي بعد **180 يوماً**.

### خطوات الفحص والمعالجة:
1. تشغيل الفاحص الآلي المدمج:
   ```bash
   npx tsx scripts/check-stale.ts
   ```
2. في حال ظهور أي قاعدة باللون الأحمر (Stale):
   - مراجعة الرابط المصدري الموثق في حقل `sourceUrl`.
   - التحقق من الجريدة الرسمية أو الموقع الحكومي للجهة المنظمة.
   - في حال عدم وجود أي تغيير تشريعي: يُعاد تحديث حقل `checkedAt` بتاريخ التدقيق الجديد مع توثيق اسم المدقق في `seo-audit/stale-audit.csv`.
   - في حال صدور تعديل تشريعي أو ضريبي: يُعدل الرقم فوراً، وتُحدث معادلة الحساب، وتُضاف حالة اختبار وحدات جديدة في `src/calculators/{calc}/calculate.test.ts`.

## 4. إرشادات إضافة وتوسيع استعلامات البحث (Keyword Expansion Playbook)

عند الرغبة في توسيع نطاق استهداف الكلمات المفتاحية في الموقع:

1. **إضافة مصطلحات البحث واللهجات**:
   - يتم التعديل في `src/seo/keywords/index.ts` ضمن كائن `CALCULATOR_KEYWORDS`.
   - تحديد الاستعلام الرئيسي (`mainQuery`)، والبدائل الدلالية (`variants`)، والمصطلحات المحلية لكل بلد (`dialectTerms`).
2. **المحافظة على قواعد العناوين**:
   - لا تتجاوز 60 حرفاً قدر الإمكان.
   - لا تكرر لاحقة الموقع أبداً: يجب أن تنتهي بعنوان مفرد `| لِسيارتك`.
   - لا تستخدم جملاً مكررة أو نصوص حشو إنشائية.
3. **الصناديق الإجابة المباشرة (Direct Answer Boxes)**:
   - يجب أن يتضمن كل حاسبة حقل `answerFirstAr` يعطي المعادلة والرقم فورياً في السطر الأول.

## 5. الحراس البرمجيون لجودة المحتوى (Content Quality Guards)

تعمل الاختبارات الآلية المدمجة في `src/__tests__/seo-content-quality-guards.test.ts` كحارس صارم ضد عقوبات Google للمحتوى المكرر أو الرقيق:

| الحارس البرمجي | الحد الأدنى / الأقصى | الإجراء عند الفشل |
| :--- | :--- | :--- |
| **تشابه الشينجلز (4-word Shingles)** | Jaccard Similarity < 70% | فشل الـ Build فورياً في حال تشابه نسختين لدولتين |
| **الحد الأدنى لكلمات الحاسبة العامة** | ≥ 400 كلمة | فشل الـ Build |
| **الحد الأدنى لكلمات حاسبة الدولة** | ≥ 400 كلمة محلية فريدة | حجب تلقائي (noindex) لحماية الدومين |
| **الحد الأدنى لكلمات الأدلة** | ≥ 800 كلمة | فشل الاختبارات |
| **الحد الأدنى لمراكز الأقسام** | ≥ 150 كلمة | حجب الأقسام التي تقل عن 3 حاسبات |
| **تطابق الأرقام في المتن مع البيانات** | مطابقة بنسبة 100% | رسالة خطأ في اختبارات الـ Unit Tests |
