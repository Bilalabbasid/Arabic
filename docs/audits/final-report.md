## 3. تفاصيل التدقيق المعماري واللوائح البرمجية

### 3.1. الالتزام الصارم بعدم استخدام أي قاعدة بيانات (Zero-Database Architecture)
- تم فحص شجرة المشروع بالكامل، ولم يتم استيراد أو تنصيب أو تهيئة أي مكتبة قواعد بيانات:
  - لا وجود لـ PostgreSQL, MySQL, MongoDB, SQLite, Redis, Supabase, Firebase, Prisma, TypeORM, Drizzle.
- جميع التعريفات والمعادلات واللوائح والمصادر مخزنة في ملفات TypeScript مقروءة ومحفوظة ضمن مستودع Git Version Control:
  - `src/data/calculators/`: مخزن الحاسبات ومحركاتها.
  - `src/countries/`: لوائح الدول المعتمدة ومحدداتها الرقمية.
  - `src/data/sources.ts`: المراجع الحكومية الرسمية.
  - `src/data/categories.ts`: الفئات والتصنيفات الـ 18.
  - `src/data/guides.ts`: الأدلة الإرشادية والمقالات المرجعية.
- تفضيلات الزائر (كالدولة الافتراضية والحاسبات المفضلة) تُدار كلياً وبشكل اختياري في متصفح العميل عبر `localStorage`.

### 3.2. بنية الروابط والسيو الدولي (International SEO Architecture)
تطبيق هيكل هرمي نقي يحقق أعلى تصنيف ممكن وفق معايير Google Search Central:
1. **الصفحة الرئيسية العالمية:** `https://lsayartk.com/` (تستعرض الحاسبات وفئات الدول).
2. **الحاسبات العامة الموحدة (Universal Calculators):**
   - الرابط الوحيد المعتمد: `https://lsayartk.com/calculators/[slug]` (مثل: حاسبة النسبة المئوية، مؤشر كتلة الجسم، حاسبة زكاة المال).
   - **منع المحتوى الضعيف (No Thin Content):** تم حظر توليد صفحات إقليمية مكررة للحاسبات العامة تحت روابط الدول (أي طلب لـ `/sa/percentage-calculator` يعيد 404 صريح).
   - وسوم `hreflang` للحاسبات العامة تحتوي فقط على `ar` و `x-default` تشير للرابط العالمي الموحد.
3. **الحاسبات المخصصة والخاضعة للوائح الدول (Country-Regulated Calculators):**
   - الرابط المعتمد: `https://lsayartk.com/[country]/[calculator]` (مثل: `https://lsayartk.com/sa/electricity-bill`).
   - تُنشأ فقط للدول التي تمت مراجعة واعتماد لوائحها الرسمية (مثل SA, AE, EG لفاتورة الكهرباء).
   - وسوم `hreflang` تبادلية 100% تربط حصرياً بين الصفحات المنشورة فعلياً للدول المعتمدة، مع `x-default` يشير إلى `/calculators/[slug]`.
4. **بوابات الدول (Country Hubs):** `https://lsayartk.com/[country]/` لجميع الدول الـ 22.
